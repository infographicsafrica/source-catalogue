# Infographics Africa source catalogue

Find the sources cited by ten [Infographics Africa](https://infographicsafrica.com/) visual explainers on energy, money, technology, public audits and trade. Each of the 18 rows pairs a published explainer with one record it cites.

[Download the CSV](InfographicsAfricaSourceCatalogue.csv) or use the [archived dataset on Zenodo](https://doi.org/10.5281/zenodo.24074503). The CSV here matches the archived download byte for byte. The explainer pages may change as new records become available.

## Reading the catalogue

| Columns | Meaning |
| --- | --- |
| `story_slug`, `story_title`, `story_url`, `topic` | The explainer’s identifier, title, permanent URL and category at the time of the snapshot. |
| `citation_order` | The order in which the citation was listed on that explainer. |
| `cited_publisher`, `cited_title`, `cited_url` | The issuer, title and link as recorded for that source. |
| `citation_date_as_recorded` | The date label recorded with the citation. It can describe a data period, an edition, a publication date or a check date. |

Follow the story URL for the figure, unit and context. Follow the cited URL for the original record and its terms. The catalogue lists references and contains no underlying third-party datasets.
